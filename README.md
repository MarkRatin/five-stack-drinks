# 五排飲料局 Demo

在終端機切換到這個資料夾後啟動預覽。

```sh
python3 -m http.server 8532 --bind 0.0.0.0
```

電腦開啟 `http://127.0.0.1:8532/`。手機與電腦在同一 Wi-Fi 時，可在手機瀏覽器開啟電腦區域網路位址加上 `:8532`。直接開啟 HTML 檔時，瀏覽器可能阻擋 JavaScript 模組和 OCR。

- 打完一場後，一次選同一局的總覽、數據和團隊截圖。核對後翻牌、揭曉反轉、確認入帳。
- 「載入試玩範例」使用預先核對的數字。範例榜及已抽牌與上傳截圖的對局分開計算。
- 瀏覽器在裝置上處理圖片，資料保存在目前網站與瀏覽器的本機儲存區。截圖未隨原始碼附上。
- 正式 GitHub Pages 發布和 Google Sheets 寫入接線在 Demo 驗收後進行。

`vendor` 包含固定版本的 Tesseract.js 6.0.1、Tesseract.js Core 6.0.0、英語和繁體中文辨識資料、遊戲結算數字和五人名單的比對特徵，以及 Noto Serif TC 固定標題字元子集。相關授權文件在同一資料夾。

## 維護牌庫

新增或調整卡片前，請先看[卡牌製作指南](CARD_DESIGN_GUIDE.md)。指南包含卡片分類、戰績欄位、塔羅插圖規格、提案範本，以及抽牌到入帳的驗收流程。

在 `rules.mjs` 的 `cards` 清單新增或修改一張計分卡。每張卡包含固定 ID、分類、顯示名稱、規則文字、需要的戰績欄位、分數單位、算分公式和排序方向。既有卡片沿用原 ID，新卡使用未出現的 ID。方向 `1` 代表數字越大越前，`-1` 代表越小越前。

```js
card('close-five', 'fun', '差五步', '死亡最接近 5 次者優先。',
  'deaths', ' 次差距', player => Math.abs(player.deaths - 5), -1)
```

公式只用已支援的欄位時，存檔後重整網站，就能在牌庫看到調整。若公式需要目前沒讀取的遊戲資料，需一起擴充 `fields`、截圖辨識和核對欄位。反轉卡在 `reversals`，用 `points` 指定原始第 1 到第 5 名的新配分，或用 `dailyBonuses` 指定本局入帳後當日總榜第 1 到第 5 名的加分。已入帳的對局保存當時的卡片與本局分數，當日總榜依對局順序結算。

牌面插圖位於 `art/`，每張圖的位置用卡片 ID 登記在 `tarot.mjs`。新增一組插圖時，把圖檔放進 `art/`，並在 `tarot.mjs` 和 `style.css` 加上對應位置。尚未配圖的卡會顯示共用牌背圖案。

## 同局重骰與追加計分

本局和歷史戰報都可按「再骰一張」，確認後替換該筆計分。已入帳的場次可按「再計分一次」，確認後新增一筆積分，和前面的計分一起納入排行榜。每次抽牌都獨立以 20% 機率抽反轉卡。歷史以對局為單位，戰報內可切換各筆計分。
